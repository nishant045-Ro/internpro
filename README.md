# internpro

An Android app built with Java and Jetpack Compose-free classic XML layouts. It includes user authentication flows (Login, Register) and a home screen, built as an internship practice project.

## Features

- User registration and login screens
- Home page after authentication
- Material design components
- Java + XML layouts

## Tech Stack

- **Language:** Java
- **UI:** XML layouts + Material Components
- **Build:** Gradle (Kotlin DSL)
- **Min SDK:** 24 (Android 7.0) / **Target SDK:** 37

## Getting Started

1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run on an emulator or device.

## Project Structure

```
app/src/main/java/com/example/internpro/
├── HomePageActivity.java
├── LoginActivity.java
├── MainActivity.java
└── RegisterActivity.java
```
